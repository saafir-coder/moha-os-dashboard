# MOHA OS — System Health Monitor

Real-time monitoring dashboard for all autonomous AI systems.

## What It Monitors

- **17 tasks** across n8n, Trigger.dev, and Supabase
- **6-hourly health snapshots** with status tracking (OK / Warning / Failing / Stale)
- **Cost tracking** per task and monthly totals
- **Alert management** with auto-deduplication fingerprinting
- **System registry** — every autonomous system registered with expected intervals

## Departments Tracked

| Department | Systems |
|-----------|---------|
| Content | LinkedIn auto-publisher, brief seeder, image generator |
| Sales | Job pipeline, job scraper, job scorer, application generator |
| Engineering | System monitor, daily digest, render engine |
| Experiments | LinkedIn A/B experiments, metrics collector |

## Tech Stack

- HTML / CSS / JavaScript (Gruvbox dark theme)
- Supabase REST API (monitoring schema)
- GitHub Pages
